更新日志

V1.46.00 完整版
  • 批量购买改为「订单式」：开启后点击各机型「加入订单」可自由搭配（如 1 架 DC-3 + 1 架 DC-4 + 2 架 DC-6），底部显示清单与合计，确认后一次性下单。
  • 宽体机头等舱补全：787 系列与 A330 全系头等舱 1-2-1 共 4 排，767-300 头等舱 1-2-1 共 3 排。
  • 购买飞机新增「批量购买」开关（一次下单 5 架）。
  • 平板开机动画改为从左上角斜向滑入，红条显示简称第 1 个字母、黄条显示第 2 个字母，其余三条显示「正在加载中...」，仍为 5 秒。
  • 飞友圈发帖后流量暴涨：先有 3 位不同飞友回复，之后每 7 秒持续随机回复与点赞，回复数量无上限且内容不重复。
  • 「航空评分」升级为「飞友圈」：首页为其他航司评价与动态，右上角头像进入个人主页（我的费用 / 我的评价 / 我的帖子）；可回复他人帖子，发帖后至少 3 位不同飞友 AI 回复。
  • 删除航空母舰（地图图标、导弹与管理员导弹面板一并移除）；平板开机动画改为红黄蓝绿紫五条斜向彩条，红黄条显示航司简称、其余显示「正在加载中...」，仍为 5 秒。
  • 平板支持自定义颜色（经典灰/曜石黑/天空蓝/樱花粉/香槟金/薄荷绿），并补齐「航图」「气象」「设置」三个 App。
  • 新增「📱 平板」：信息栏按钮打开灰色平板，按电源键开机，5 秒丝滑开机动画（航司名称 + 简称），进桌面后可打开 App——登录/一键填充、五星星级、顾客评价、发帖与点赞。
  • 新增「新手教程」：主界面点击后由机长一步步引导——开始游戏、命名、选枢纽、联盟可选、购买飞机、等待交付、返回大地图。
  • 涂装预览按机型显示对应飞机照片：DC-3 / DC-4 / CRJ-900 / E175 / 737-800 / A330 全系，其余机型沿用默认图；染色区域按每架飞机的轮廓自动适配。
  • 新增 A330 系列：A330-200 / A330-300 / A330neo（-800 / -900），三舱 1-2-1 / 2-2-2 / 2-4-2 布局，头等舱前带吧台，舱段间设服务区与左右舱门。
  • 座位图新增排号显示，宽体机支持多舱段与部分排减座。
  • A320 系列：点击可选 A318/A319/A320/A321，再选 ceo / neo；A321neo 另有 LR / XLR 远程型。
  • 涂装界面新增实时飞机预览，支持自由绘制花纹、贴纸、橡皮与撤销。
  • 新增机上服务·餐饮系统，4阶段升级可提升航班收入。
  • 新增空客 A320，公务舱2-2、经济舱3-3，航程6100km。
  • 新增空客 A220 机型，包含公务舱与隔板。
  • 座位图使用更真实的样式，并随腿部空间动态缩放。
  • 强制弧形航线、B-1顺序编号。
  • 修复了空难接管时，如果飞机在地面则无法操控的Bug。
  • 新增波音737-800，包含商务舱、紧急出口和12排2-2布局。
